## 🧰 Claude Code Skills

[Agent Skills](https://agentskills.io) I build and use myself. This repository is itself a Claude Code plugin.
The skills are written in Korean.

| Skill | What it does |
|---|---|
| [`tstory`](./skills/tstory) | Turns lecture material (PDF, PPTX) into a Tistory blog manuscript, thumbnail, and figures |
| [`book-study`](./skills/book-study) | Reads photos of underlined book pages and builds review pages in Notion |
| [`resume`](./skills/resume) | Tailors a resume to a job posting and fills Word application forms without breaking their formatting |
| [`effective-python`](./skills/effective-python) | Writes and reviews Python code following the 90 rules of *Effective Python* (2nd ed.) |
| [`pragmatic-programmer`](./skills/pragmatic-programmer) | Uses *The Pragmatic Programmer* principles (ETC, DRY, orthogonality, reversibility) when designing and reviewing code |
| [`book-voice`](./skills/book-voice) | Writes in the voice and structure of books the author studied (*The Pragmatic Programmer*, *Effective Python*) |

### 📦 Install

In Claude Code:

```
/plugin install doubles2-skills --marketplace Doubles2/Doubles2
```

The plugin updates itself on every push.
Skills reference assets by path, so clone the repository to `~/code/doubles2`.

```bash
git clone https://github.com/Doubles2/Doubles2.git ~/code/doubles2
```
