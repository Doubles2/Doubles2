# 사람이 쓴 글처럼 쓰기

사용자는 책을 한 번 읽고 밑줄을 그어 공부한다. 그 책들은 주제가 다르지만 모두 **사람이 쓴 글**이다.
이 스킬은 책별 말투를 흉내 내는 게 아니라, 다섯 책에서 모은 **글쓰기 동작**으로 상황에 맞는 글을 쓴다.

- 글쓰기 동작 모음: `references/human-writing.md` ← 글을 쓸 때마다 읽는다.
- 책별 관찰 노트: `references/books/<책>.md` ← 사용자가 특정 책 말투를 콕 집을 때, 또는 동작의 실제 모습이 더 필요할 때만.

## 1. 쓰는 순서

1. **누가 누구에게 말하는가**를 정한다. 주제가 아니라 관계로 고른다(선배→후배, 동료→동료, 나→당신, 코치→연습생). 사용자가 형식(존댓말, 슬랙, 공문)을 정했으면 그것이 먼저다.
2. **한 문장 핵심**을 뽑는다. 명령형이나 비교형("A보다 B")으로. 이게 안 나오면 아직 쓸 때가 아니다.
3. `references/human-writing.md` 9번 표에서 상황에 맞는 조합을 출발점으로 잡고, 여는 법·본문·끝내는 법 동작을 고른다. 한 책 틀을 통째로 쓰지 않고 섞어도 된다.
4. 예는 사용자의 실제 환경(데이터 사이언스, 리테일 수요 예측, 파이썬, 노션 공부)에서 구체적으로(이름·숫자·장면) 고른다.
5. 쓴다. 다 쓰면 아래 점검표와 `human-writing.md` 10번(AI 티 vs 사람 글)으로 고친다.

답변 첫 줄에 "어떤 관계·동작으로 썼는지"를 한 줄로 밝힌다(예: "선배→후배 조언, 실패 장면으로 열고 Tip 한 줄로 닫음").

## 2. 점검표

- [ ] 한 문장 핵심이 눈에 띄게 있는가?
- [ ] 시점(우리/나, 여러분/당신)과 어미가 처음부터 끝까지 같은가?
- [ ] 추상적인 주장마다 구체적인 예(장면·대사·코드·숫자)가 붙었는가?
- [ ] 문단 길이와 문장 길이가 섞여 있는가? 불릿이 문단을 대신하고 있지 않은가?
- [ ] 입장이 드러나는가? 장단점만 늘어놓고 끝나지 않았는가?
- [ ] 끝이 열려 있지 않은가? (기억할 것·원칙 한 줄·처음 장면으로 돌아가기·숙제 중 하나)
- [ ] 책 문장을 그대로 옮긴 곳, 지어낸 근거·출력이 없는가?
- [ ] 사용자가 정한 분량·형식을 지켰는가?

## 3. 하지 말 것

- 책 본문을 문단째 옮기기. 이 repo는 공개다.
- 연구·통계·인용·코드 출력을 지어내기.
- 번역투를 일부러 과장하기("~에 있어서", "~하는 것이 요구된다").
- 사용자가 다른 말투를 정했는데 이 스킬의 말투를 고집하기.

## 4. 공부가 늘면 갱신하기

사용자가 `/Users/soonwon/study/책/공부_<책>/내용/*/원본/`에 새 사진을 넣고 "book-voice 업데이트"를 요청하면:

1. 참고 파일 앞머리에 적힌 "어디까지 읽었는지"와 폴더를 비교해 새로 들어온 항목만 찾는다.
2. 새 사진을 `sips -Z 1500`으로 줄여 Read한다. 밑줄(형광펜)과 글의 구성·문장 습관을 본다.
3. 새로 보인 동작은 `references/human-writing.md`의 알맞은 절에 **동작으로** 추가한다(책 이름은 괄호 힌트로만).
4. 그 책에서만 보이는 구체적인 관찰은 `references/books/<책>.md`에 적고 앞머리의 읽은 범위를 고친다.
5. 새 책이면 `references/books/<책-슬러그>.md`를 만들고, `human-writing.md` 앞머리 책 목록과 이 파일 description에 책 이름을 넣는다.
