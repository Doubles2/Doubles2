# 책 공부 복습 노트

## 사용자의 공부법
책을 **한 번** 읽고 밑줄 → Claude가 정리 → 그 페이지를 **계속 보며 중요한 것을 기억**한다.
- 페이지는 완성된 **복습용**이다. 사용자가 직접 쓰는 빈칸·"직접 써 보세요" 안내를 두지 않는다.
- 맨 위만 봐도 **이 항목이 말하고 싶은 것**과 **예제**가 떠올라야 한다.
- 항목마다 한 번만 정리한다. 재독 계획·실천 체크(해볼 것, 해봤나, 다시 읽을 날)는 만들지 않는다.

## 절차
1. **사진 읽기**
   - 원본은 4~5MB이므로 `sips -Z 1800 "<원본>" --out <scratchpad>/<이름>.jpg`로 줄인 사본을 Read한다.
   - 여러 장이면 파일명(KakaoTalk_Photo_날짜-시각) 순서가 읽은 순서다. 보통 두 쪽 펼침 1장이고 쪽 번호는 각 쪽 하단에 있다.
   - 노란 형광펜 = 밑줄 = 사용자가 중요하다고 본 곳 → 📝와 ❓의 우선 재료.
   - 밑줄이 없으면 책 흐름대로 정리하고, 질문 재료는 책의 "기억해야 할 내용"이나 핵심 주장에서 뽑는다.
   - 사진에 **앞뒤 항목**이 걸쳐 있으면 해당 항목 범위만 정리한다. 장 소개글은 "N장 정리" 페이지로 보낸다.
   - 판독이 애매한 문장은 답변에서 사용자에게 책과 대조해 달라고 알린다.
2. **노션 위치 확인**: 책의 노션 상위 페이지를 fetch해서 기존 구조를 따른다. 노션 마크다운 스펙(`notion://docs/notion-flavored-markdown-spec`)을 처음 한 번 fetch한다.
3. **페이지 작성**: 아래 틀대로. 로컬 `정리.md`는 만들지 않는다(정리는 노션 한 곳).
4. **장 정리**: 장의 마지막 항목을 정리했으면 "N장 정리" 페이지를 만들거나 채운다.
   - 장 지도 표(장 소개글 밑줄 ↔ 이어지는 항목), 항목별 한 줄 핵심, 장을 한 문장으로.

## 노션 서식 (사용자 지정)
- 제목 단계별 색. 사용자 상위 페이지가 배경색 제목(`h1 blue_bg` 등)을 쓰므로 **배경색**으로 준다. 태그 형식으로 쓴다:
  ```
  <h1 color="gray_bg">
  한눈에 보기
  </h1>
  ```
  - 대제목 `<h1 color="gray_bg">` — 회색
  - 중제목 `<h2 color="orange_bg">` — 주황
  - 소제목 `<h3 color="green_bg">` — 초록
  - 사용자가 글자색을 원하면 `_bg`를 뗀다(`gray`, `orange`, `green`).
- 강조는 **굵게 + 밑줄**: `<b><u>강조할 말</u></b>`. 📌 한 줄 핵심, 📝 핵심어, 질문 답의 핵심어, 본문 핵심 문장에 쓰고, 한 문단에 한두 군데만.
- 페이지는 대제목 세 개로 나눈다: `한눈에 보기`(📌💬📝) → `떠올려 보기`(❓) → `자세히 보기`(▶🔗📎). 각 섹션 이름은 중제목, 섹션 안의 묶음(예제 종류, 책 흐름의 소제목, 🔗 안의 항목)은 소제목. 그보다 더 나눌 때는 제목 대신 굵은 줄을 쓴다.
- 토글 안에도 제목 태그를 쓸 수 있다(`<toggle>` 첫 줄이 토글 이름, 빈 줄 뒤에 자식 블록).
- **넓게 보기**: 모든 페이지를 넓게 보기로 만든다. 새 페이지는 `notion-create-pages`에 `full_width: true`, 기존 페이지는 `notion-update-page`(command `update_properties`)에 `full_width: true`. DB 행 페이지도 페이지마다 설정한다.
- "N장 정리" 페이지도 같은 서식을 따른다.
