# projects

코드·모델 작업은 여기에 폴더 하나씩 만든다. 각 폴더가 포트폴리오 항목 하나다.

## 규칙

- 폴더 이름: `<YYYY-MM>-<짧은-영문-이름>` (예: `2026-12-demand-forecast`)
- 폴더마다 독립적으로 돌아가야 한다. 의존성은 그 폴더 안에 둔다 (`pyproject.toml` + `uv`, 또는 `package.json`).
- 폴더마다 `README.md`를 아래 카드 형식으로 쓴다. 루트 README의 프로젝트 표는 이 카드에서 만든다.
- 그 프로젝트에만 해당하는 에이전트 규칙은 그 폴더의 `CLAUDE.md`에 둔다.
- 데이터, 모델 가중치, `.env`는 커밋하지 않는다. 받는 방법이나 만드는 방법을 README에 적는다.
- 노트북은 출력을 지우고 커밋한다.

## README 카드 형식

```markdown
# <프로젝트 이름>

> 한 줄 요약

| 항목 | 내용 |
|---|---|
| 기간 | 2026.12 ~ 2027.01 |
| 분야 | 시계열 예측 / 추천 / 웹 … |
| 스택 | Python, LightGBM, … |
| 결과 | 핵심 수치나 결과물 한 줄 |

## 문제
## 접근
## 결과
## 배운 점 (wiki 링크)
## 실행 방법
```
