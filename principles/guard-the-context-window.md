# Guard the Context Window

컨텍스트는 한 세션 안에서 다시 채울 수 없다. 필요한 것만, 필요할 때 읽는다.

**Why:** 쓸데없이 읽은 파일과 큰 출력은 뒤에 올 판단의 자리를 빼앗는다. 세션이 길수록 앞에서 낭비한 것이 비싸진다.

**이 스킬들에서:**
- SKILL.md는 라우팅이다. 세부 목록(Topic 53개, Better Way 90개, 책별 관찰)은 `references/`에 두고, 해당 장·책이 필요할 때만 읽는다.
- 매번 쓰는 것(노션 페이지 틀, 끝맺음 요약 템플릿)은 SKILL.md 본문에 둔다. 별도 파일이면 매번 한 번 더 읽어야 한다.
- 원본 사진은 줄인 사본을 읽는다. 앞뒤 항목이 걸친 사진은 해당 범위만 본다.
- 큰 탐색(여러 폴더·여러 노션 페이지 훑기)은 결론만 필요하면 서브에이전트에 맡기고 요약만 받는다. 파일 몇 개면 직접 읽는다(위임 비용이 더 크다).

**테스트 질문:** "이걸 읽지 않으면 이번 판단이 틀리나?" 아니면 읽지 않는다.
