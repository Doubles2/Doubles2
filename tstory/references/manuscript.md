# 원고(post.md) 형식 — 글쓰기 화면에 직접 옮겨 적는 지시서

이 블로그는 **HTML 모드를 쓰지 않습니다.** 티스토리 글쓰기(기본모드)에 직접 타이핑하고
툴바로 서식을 지정합니다. 그래서 `post.md`는 원고이면서 **작업 지시서**여야 합니다.

원칙: 위에서 아래로 읽으며 그대로 따라 하면 글이 완성될 것.

> 이 문서의 값은 전부 **발행된 글의 HTML을 다시 읽어 맞춘 것**입니다.
> 마지막 대조: [#145 클로드 코드의 정석 #1](https://doubles-won.tistory.com/145)

## 티스토리 기본모드 툴바

| 드롭다운 | 선택지 |
|---|---|
| **스타일** | 제목1 · 제목2 · 제목3 · 본문1 · **본문2(기본값)** · 본문3 |
| **서체** | **기본서체(기본값)** · 본고딕 R · 본고딕 L · 나눔고딕 · 본명조 · 궁서 |
| **이미지** | 사진 · 파일 · 슬라이드쇼 |

**pt/px를 직접 넣는 칸은 없습니다.** 크기는 스타일 프리셋이 정합니다.

### 프리셋 ↔ 실제 크기

**이름과 태그가 한 칸씩 어긋납니다.** 제목1이 `h2`입니다 — 헷갈리기 쉬우니 주의.

| 프리셋 | 나오는 태그 | 크기 | 이 블로그에서 |
|---|---|---|---|
| **제목1** | `h2` | size26 | ✅ 대단원 |
| **제목2** | `h3` | size23 | ✅ 소단원 |
| 제목3 | `h4` | size20 | ❌ 안 씀 |
| 본문1 | `p` | size18 | ❌ 안 씀 |
| **본문2** | `p` | size16 | ✅ 본문 (기본값) |
| 본문3 | `p` | size14 | ❌ 안 씀 |

**서체는 기본서체 그대로 둡니다.** 예외는 남의 말을 옮기는 `(인용문)` 하나뿐입니다.

## 블록 태그

각 덩어리 **앞줄에** 괄호 태그를 놓고, 다음 줄부터 실제 내용을 씁니다.
태그와 내용을 분리해야 내용만 깔끔하게 드래그해 복사할 수 있습니다.

```
(제목1)
🎯 1. 왜 10단계를 다시 보나

(본문2)
지난 편은 **"어디서 문제가 터지나"**에 초점이 있었습니다.
```

### 태그 목록

| 태그 | 티스토리 조작 | 결과 |
|---|---|---|
| `(제목1)` | 스타일 → **제목1** | `h2` 26px |
| `(제목2)` | 스타일 → **제목2** | `h3` 23px |
| `(본문2)` | 기본값 — 아무것도 안 해도 됨 | `p` 16px |
| `(본문2 · 회색)` | 글자색 → **회색** | `#9d9d9d` |
| `(인용구)` | 인용구 버튼 → **스타일2** | 내 생각 · 💡 · ⚠️ · 👉 |
| `(인용문)` | 인용구 **스타일1** + 서체 **본명조** | 남의 말을 그대로 옮길 때 |
| `(표 헤더)` | 기울임 (⌘I) | 표 바로 위 한 줄 |
| `(목록)` | 불릿 목록 버튼 | `ul` |
| `(번호목록)` | 번호 목록 버튼 | `ol` |

| `(코드블록 · 언어)` | 코드블록 버튼 | `pre` 14px |
| `(구분선)` | 구분선 → **스타일5** | `hr` |
| `(태그 칸 입력용)` | 본문 아님 — 태그 입력칸 | 맨 마지막 |

제목3·본문1·본문3은 쓰지 않습니다.

## 인용구는 두 종류입니다

| | 언제 | 티스토리 |
|---|---|---|
| `(인용구)` | 도입부, 💡 내 해석, ⚠️ 함정, 👉 다음 편 | 스타일2, 기본서체 |
| `(인용문)` | **남이 한 말**을 그대로 옮길 때 | 스타일1, 본명조 |

`(인용문)`은 출처를 `—`로 밝힙니다.

```
(인용문)
자질구레한 일에 시달리지 않아도 돼서 코딩이 그 어느 때보다 즐겁다. ↵
— Boris Cherny, Claude Code 개발자
```

## 표

**티스토리 표에는 헤더 행 개념이 없습니다.** 만들면 전부 일반 칸(`td`)이 됩니다.
그래서 **헤더는 표 바로 위에 기울임 한 줄**로 쓰고, 표에는 데이터 행만 넣습니다.

```
(표 헤더)
모델 · 특성 · 적합한 작업

(표 · 3열)
| Haiku | 빠른 응답 | 간단한 질문 · 코드 자동완성 |
| Sonnet | 속도와 품질의 균형 | 대부분의 코딩 작업 |
| Opus | 깊은 추론 | 복잡한 아키텍처 결정 |
```

마크다운의 `| --- |` 구분선은 **쓰지 않습니다** — 옮길 때 그냥 한 행이 돼버립니다.

## 이미지

```
(fig-01.png 삽입) — 에이전틱 루프 3단계와 사용자 개입 지점
```

- 파일명은 글 폴더에 실제로 있는 파일과 일치해야 합니다 (`check_md.py`가 검사)
- **`—` 뒤 문장은 실제 캡션으로 들어갑니다.** 티스토리 이미지 아래 캡션 칸에 그대로 입력하세요.
  그래서 "무슨 그림인지 메모"가 아니라 **독자에게 읽힐 한 줄**로 써야 합니다
- 삽입은 그 자리에 커서를 두고 **이미지 버튼 → 사진**

## 문단은 짧게 씁니다

발행글을 재보니 **문단 92개에 문장은 대부분 1~2개**입니다.
손으로 옮겨 적는 글이라 긴 문단은 치기도 읽기도 부담스럽습니다.

한 문단에 세 문장 이상 들어가면 `(본문2)` 블록을 나누세요.

## 값이 안 맞을 때 확인하는 법

1. 글쓰기 새 글에 각 프리셋·버튼으로 한 줄씩 칩니다
2. 우측 상단 **기본모드 → HTML**을 한 번 누릅니다
3. `data-ke-style="style2"` 처럼 실제 값이 그대로 보입니다
4. **기본모드**로 되돌리고 그 글은 버립니다

이 문서의 값(인용구 style2, 구분선 style5, 회색 `#9d9d9d`)은 전부 발행글 HTML에서 확인했습니다.
