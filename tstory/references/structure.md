# 글 구성 5단계 + 아이콘

## 필수 골격

모든 글은 아래 순서를 따릅니다. 각 단계는 `(제목1)` 하나 이상입니다.

```
[도입 인용구]            ← (인용구), 2줄
[상단 출처 문구]          ← attribution.md
────────────────
① 개요 (서론)            ← 왜 이걸 보는가 / 무엇을 풀려는가
② 본론                   ← (제목1) 2~5개. 여기가 글의 몸통
③ 결과                   ← 그래서 무엇이 되었나 / 확인된 것
④ 최종 요약              ← 전체를 한 문장으로 압축
⑤ 향후 계획              ← 앞으로 볼 것. 마무리 본문 안에 녹입니다 (별도 👉 블록 ✕)
────────────────
[하단 출처 문구]          ← attribution.md
[해시태그 한 줄]          ← 복사 붙여넣기용
```

`④ 최종 요약`과 `⑤ 향후 계획`은 실제 발행글에서 `✍️ 마무리 & 다음 단계` **한 개의 (제목1)**로
합쳐지는 경우가 많습니다. 둘 다 내용이 충분하면 나누고, 아니면 합쳐도 됩니다.

## 대단원 제목 형식

`{이모지} {번호}. {제목}`

- 번호는 아라비아 숫자(`1.`) 또는 원문자(`①`) — **한 글 안에서는 통일**
- 개요/마무리 단원은 번호를 생략하기도 합니다 (`🎯 핵심 원리 — 점진적 로딩 3계층`)
- 제목에 em dash로 부연을 붙이는 형태가 잦습니다

### 사용 규칙

- **한 글에 같은 아이콘을 두 번 쓰지 않습니다.**
- 이모지는 대단원 제목 맨 앞에만. 본문 문장 안에는 넣지 않습니다
  (예외: 💡·⚠️로 시작하는 인용구, 📎 출처).
- 톤이 튀는 이모지(🤣 🔥 💯 🎉)는 쓰지 않습니다. 차분한 계열로 유지.

## 분량 기준 (실측)

**기준은 #147입니다** — 제가 쓴 초고를 저자가 직접 다듬어 발행한 가장 최근 글이라,
저자가 실제로 원하는 밀도를 그대로 보여줍니다.

| | 제 초고 | **#147 (저자 수정 후)** |
|---|---|---|
| 대단원 (h2) | 7개 | 7개 — 그대로 |
| 소단원 (h4) | 3개 | 3개 — 그대로 |
| 문단 | 72개 | **24개 — 3분의 1로 합쳐짐** |
| 인용구 | 9개 | **8개** (👉 다음 편이 삭제됨) |
| 그림 | 5개 | 5개 — 그대로 |
| 표 | 3개 | 3개 — 그대로 |
| 굵게 : 밑줄 | — | 33 : 39 (밑줄이 더 많음) |

**구조는 손대지 않고 문단만 합쳤습니다.** 대단원·소단원·그림·표 개수는 초고 그대로 통과했으니
그 밀도는 맞습니다. 문제는 문단을 한 문장씩 끊은 것뿐이었어요.

**한 문단 = 3~6문장.** 화제가 바뀔 때만 `(본문2)` 블록을 나눕니다.

**💡 인용구는 3개 이상** 있어야 이 블로그 톤이 납니다 (#147은 6개 + ⚠️ 1개).
`👉 다음 편` 예고 인용구는 넣지 않습니다.
