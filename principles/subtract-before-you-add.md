# Subtract Before You Add

기본 행동은 빼기다. 무언가를 더하기 전에, 이미 있는 것과 겹치는지 보고 합치거나 지운다.

**Why:** 스킬과 노트는 더하기만 하면 비대해지고, 같은 말이 여러 곳에 적혀 서로 어긋난다. 얇고 정확한 문서가 두껍고 포괄적인 문서보다 잘 지켜진다.

**이 스킬들에서:**
- 같은 규칙을 SKILL.md와 references에 두 번 적지 않는다. SKILL.md에는 이름과 번호만, 설명은 references 한 곳에.
- book-voice에 새 동작을 넣기 전에, 뜻이 같은 기존 동작이 있으면 그 줄을 다듬는다. 책별 노트에는 공통 동작으로 옮기지 않은 그 책만의 관찰만 남긴다.
- 공부한 내용을 스킬에 반영할 때 "더 넣을 것"보다 "이제 필요 없어진 것"을 먼저 찾는다.
- 쓸 근거가 없는 섹션은 빈칸으로 두지 말고 뺀다.

**테스트 질문:** "이 줄이 없으면 Claude가 실제로 틀리나?" 아니면 지운다.

**경계:** 사용자가 직접 쓴 내용이나 사용자가 정한 형식은 묻지 않고 지우지 않는다.
