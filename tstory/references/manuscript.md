# 원고(post.md) 형식 — 글쓰기 화면에 직접 옮겨 적는 지시서

이 블로그는 **HTML 모드를 쓰지 않습니다.** 티스토리 글쓰기(기본모드)에 직접 타이핑하고
툴바로 서식을 지정합니다. 그래서 `post.md`는 원고이면서 **작업 지시서**여야 합니다.

원칙: 위에서 아래로 읽으며 그대로 따라 하면 글이 완성될 것.

## 티스토리 기본모드 툴바 (실제 화면 확인)

| 드롭다운 | 선택지 |
|---|---|
| **스타일** | 제목1 · 제목2 · 제목3 · 본문1 · **본문2(기본값)** · 본문3 |
| **서체** | **기본서체(기본값)** · 본고딕 R · 본고딕 L · 나눔고딕 · 본명조 · 궁서 |
| **이미지** | 사진 · 파일 · 슬라이드쇼 |

**pt/px를 직접 넣는 칸은 없습니다.** 크기는 스타일 프리셋이 정합니다.
그래서 원고에는 **프리셋 이름만** 적습니다.

### 프리셋 ↔ 실제 크기 (에디터에서 직접 확인함)

**이름과 태그가 한 칸씩 어긋납니다.** 제목1이 h2입니다 — 헷갈리기 쉬우니 주의.

| 프리셋 | 나오는 태그 | 크기 | 이 블로그에서 |
|---|---|---|---|
| **제목1** | `h2` | size26 | ✅ 대단원 |
| **제목2** | `h3` | size23 | ✅ 소단원 |
| 제목3 | `h4` | size20 | ❌ 안 씀 |
| 본문1 | `p` | size18 | ❌ 안 씀 |
| **본문2** | `p` | size16 | ✅ 본문 (기본값) |
| 본문3 | `p` | size14 | ❌ 안 씀 |

기존 12편의 본문이 `size16`이고 **본문2가 정확히 size16**이라, 기본값 그대로 쓰면 됩니다.

**서체는 어디서도 바꾸지 않습니다.** 기본서체가 기존 12편과 같은 모양이라,
나눔고딕 같은 걸 고르면 오히려 톤이 어긋납니다. 그래서 태그에 서체를 적지 않습니다 —
적혀 있지 않으면 "기본서체 그대로"라는 뜻입니다.

## 블록 태그

각 덩어리 **앞줄에** 괄호 태그를 놓고, 다음 줄부터 실제 내용을 씁니다.
태그와 내용을 분리해야 내용만 깔끔하게 드래그해 복사할 수 있습니다.

```
(제목1)
🎯 1. 왜 10단계를 다시 보나

(본문2)
지난 편은 **"어디서 문제가 터지나"**에 초점이 있었습니다.
```

### 태그 목록

| 태그 | 티스토리 조작 |
|---|---|
| `(제목1)` | 스타일 → **제목1** (대단원, 26px) |
| `(제목2)` | 스타일 → **제목2** (소단원, 23px) |
| `(본문2)` | 기본값 — **아무것도 안 해도 됨** (16px) |
| `(본문2 · 회색)` | 글자색 버튼 → 회색(`#999999`) |
| `(인용구)` | 인용구 버튼 → 스타일1 |
| `(목록)` | 불릿 목록 버튼 |
| `(번호목록)` | 번호 목록 버튼 |
| `(표 · N열)` | 표 버튼 → 열/행 지정 |
| `(코드블록 · 언어)` | 코드블록 버튼 |
| `(구분선)` | 구분선 버튼 → 스타일1 |

제목3·본문1·본문3은 이 블로그에서 쓰지 않습니다.
글 제목은 티스토리 **제목 칸**이 담당하므로 본문 맨 위에 제목을 또 넣지 않습니다.

## 이미지

이미지는 **자기 줄에** 이렇게 씁니다.

```
(fig-01.png 삽입) — ML 라이프사이클 10단계를 세 국면으로 묶은 도식
```

- 파일명은 글 폴더에 실제로 있는 파일과 일치해야 합니다 (`check_md.py`가 검사)
- ` — ` 뒤 설명은 무엇을 넣는 그림인지 알아보기 위한 것 (본문에는 안 들어감)
- 티스토리에서는 그 자리에 커서를 두고 **이미지 버튼 → 사진**

## 인라인 서식

| 원고 표기 | 티스토리 조작 |

## 확인 방법 (다른 값이 궁금할 때)

프리셋이 실제로 어떤 태그·크기를 내는지는 이렇게 확인합니다.

1. 글쓰기 새 글에 각 프리셋으로 한 줄씩 칩니다
2. 우측 상단 **기본모드 → HTML**을 한 번 누릅니다
3. `<h2 data-ke-size="size26">` 처럼 태그와 크기가 그대로 보입니다
4. **기본모드**로 되돌리고 그 글은 버립니다

위 표는 이 방법으로 확인한 결과입니다. HTML 모드는 이 확인에만 쓰고, 글은 기본모드로 씁니다.
